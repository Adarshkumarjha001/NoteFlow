NoteFlow helps users create, organize, search, and manage personal notes through a clean, responsive interface. The project combines a React frontend with an Express/Node.js backend and MongoDB persistence.
🚀 Features
🔐 Authentication
- User registration and login
- JWT-based authentication
- Password hashing with bcrypt
- Protected routes and authenticated API access
- Form validation and error handling
🗒️ Note Management
- Create, edit, and delete notes
- Pin and unpin important notes
- Mark notes as favorites
- Archive and unarchive notes
- Organize notes by category
- Add tags and choose note colors
🔎 Search & Organization
- Search notes by title, content, and tags
- Dedicated views for all notes, pinned notes, favorites, and archived notes
- Category-based navigation
- Dashboard statistics for notes, pinned items, favorites, and archived items
🎨 User Experience
- Responsive layout for desktop, tablet, and mobile
- Light and dark themes
- Loading indicators and toast notifications
- Password visibility toggle
- Reusable React components
- Gradient styling, transitions, and interactive UI elements

⚙️ Getting Started
Prerequisites
Install the following before you begin:
- Node.js and npm
- MongoDB Community Server or MongoDB Atlas
- Git
Use a Node.js version compatible with the dependencies in the project.
1. Clone the repository
git clone https://github.com/Adarshkumarjha001/NoteFlow.git
cd NoteFlow


2. Set up the backend
cd server
npm install


Create a server/.env file. Use this example as a guide and adjust the values for your environment:
PORT=5000
NODE_ENV=development
MONGO_URI=mongodb://127.0.0.1:27017/noteflow
JWT_SECRET=replace_with_a_strong_random_secret
JWT_EXPIRE=7d
CLIENT_URL=http://localhost:5173


Configuration tips
- For MongoDB Atlas, replace MONGO_URI with your Atlas connection string.
- Generate a strong, unique value for JWT_SECRET.
- Set CLIENT_URL to the frontend's actual origin.
- Never commit your real .env file or credentials.
Start the backend development server:
npm run dev


The backend should use http://localhost:5000 when configured with the example port.
3. Set up the frontend
Open a second terminal from the project root:
cd client
npm install


Create a client/.env file:
VITE_API_URL=http://localhost:5000


Start the frontend:
npm run dev


Open the local URL printed by Vite in the terminal. The default is commonly http://localhost:5173.
Keep the frontend and backend running in separate terminals. If your configured ports differ, update the environment variables accordingly.

▶️ Run the Application
1. Start MongoDB or confirm that your MongoDB Atlas database is accessible.
2. Start the backend from server/ with npm run dev.
3. Start the frontend from client/ with npm run dev.
4. Open the frontend URL printed in the terminal.
5. Register an account or sign in.
6. Create a note and try the available organization features.
🔌 API Overview
The endpoints below describe the expected API surface. Confirm the route paths and methods against the current backend before relying on this list.
Authentication
Method	Endpoint	Description
POST	/api/auth/register	Register a user
POST	/api/auth/login	Log in
GET	/api/auth/me	Get the current user
Notes
Method	Endpoint	Description
GET	/api/notes	Retrieve notes and supported filters
GET	/api/notes/:id	Retrieve one note
POST	/api/notes	Create a note
PUT	/api/notes/:id	Update a note
DELETE	/api/notes/:id	Delete a note
PATCH	/api/notes/:id/pin	Toggle pin status
PATCH	/api/notes/:id/favorite	Toggle favorite status
PATCH	/api/notes/:id/archive	Toggle archive status
Supported query parameters depend on the implementation and may include category, pinned status, favorite status, archived status, and search.

🛡️ Security Notes
- Keep real .env files and credentials out of version control.
- Store password hashes, not plain-text passwords.
- Keep JWT secrets on the backend.
- Validate incoming data on the server.
- Check note ownership for operations on individual notes.
- Configure CORS for the intended frontend origin.
- Avoid exposing sensitive server errors in production.
